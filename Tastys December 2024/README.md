# Tastys

Discover, rate and share the best dishes around you.

**Version:** 0.8.2 (December 2024)

## Features

- Splash screen
- Restaurant list
- Restaurant & dish detail
- Star ratings
- Search with cuisine filters
- Tab bar navigation
- Bookmarks
- Distance sorting
- MVVM view models
- Rate a dish
- Plates
- Dietary filters
- Leaderboard
- Activity feed
- Onboarding
- Food profile

## Requirements

- Xcode 15.4+, iOS 17.0+

## Getting started

1. Open `Tastys.xcodeproj`.
2. Select the `Tastys` scheme.
3. Run on an iPhone simulator.

See CHANGELOG.md for release history.
