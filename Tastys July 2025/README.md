# Tastys

Discover, rate and share the best dishes around you.

**Version:** 0.11.0 (July 2025)

## Features

- Splash screen
- Restaurant list
- Restaurant & dish detail
- Star ratings
- Search with cuisine filters
- Tab bar navigation
- Bookmarks
- Distance sorting
- MVVM view models
- Rate a dish
- Plates
- Dietary filters
- Leaderboard
- Activity feed
- Onboarding
- Food profile
- Supabase backend
- Email sign-in / sign-up
- Editable profiles
- Followers
- Photo posts

## Requirements

- Xcode 15.4+, iOS 17.0+
- Swift Package Manager: supabase-swift

## Getting started

1. Open `Tastys.xcodeproj`.
2. Select the `Tastys` scheme.
3. Run on an iPhone simulator.

The Supabase URL and publishable key live in `supabase/Supabase.swift`.

See CHANGELOG.md for release history.
